# Responsive Personal Blog Website

## Overview

This project is a **Responsive Personal Blog Website** built using **HTML** and **CSS**. The website showcases a clean, user-friendly design that adjusts seamlessly to different screen sizes, from desktop to mobile, ensuring a smooth experience across all devices. The blog layout is simple yet modern, allowing users to read content comfortably and explore different sections easily.

## Features

- **Fully Responsive Design**: The layout adjusts dynamically to fit devices of all sizes, including smartphones, tablets, and desktops.
- **Customizable**: The website structure is easy to modify and expand with additional pages or blog entries.
- **Clean and Minimalist Layout**: Focuses on readability and user experience with a minimalistic design.
- **Cross-Browser Compatibility**: Tested across modern web browsers to ensure a consistent experience.

## Technologies Used

- **HTML5**: For structuring the website content.
- **CSS3**: For styling and ensuring responsive design using media queries and flexible layouts.

## Installation and Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Andrianna-Mitchell/personalblog.git
   ```
2. **Navigate to the project folder**:
   ```bash
   cd personalblog
   ```
3. **Open the `index.html` file in your browser** to view the website locally.

## Usage

This project serves as a starting template for a personal blog. You can modify the HTML files to add your own blog posts, update images, and further customize the design. The CSS file includes media queries to ensure the layout adapts to different screen sizes.
